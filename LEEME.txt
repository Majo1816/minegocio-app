Café Tierra Querida — Actualización: Supabase + roles + rebranding
======================================================================

QUÉ CAMBIÓ EN ESTA VERSIÓN
-----------------------
- Nombre y logo aplicados: "Café Tierra Querida" en el encabezado, la
  pantalla de inicio, el título de la pestaña del navegador y el ícono.
- Pantalla de login: ya no se puede entrar sin usuario y contraseña.
- Los datos ahora se guardan de VERDAD en una base de datos (Supabase):
  productos, ventas, compras y gastos ya no se borran al recargar.
- Dos roles:
    - Empleado: puede registrar ventas, compras, gastos, ver inventario,
      reportes y cuentas por cobrar/pagar (todo lo operativo).
    - Administrador: además, puede eliminar gastos y entrar a una
      pantalla de "Administración" (ícono de engranaje arriba a la
      derecha) donde ve el equipo y puede ascender/quitar administradores.
- Botón de cerrar sesión (ícono de salida, arriba a la derecha).

CÓMO SUBIR ESTOS CAMBIOS (ya tienes el repo conectado a Vercel)
-----------------------
Como ya hiciste todo el proceso de Git + GitHub + Vercel antes, ahora
actualizar la app es mucho más simple:

1. Reemplaza TODOS los archivos de tu carpeta local (la que ya tiene el
   .git dentro, en Downloads\MiNegocio_App o donde la hayas dejado) por
   los que vienen en este .zip. Es decir: sobrescribe index.html,
   bundle.js, styles.css, agrega logo.png, y reemplaza los archivos
   *.source.* — pero NO borres la carpeta .git que ya está ahí.

2. Abre tu terminal en esa misma carpeta (la que ya tiene el historial de
   Git) y ejecuta:

   git add -A
   git commit -m "Rebranding Cafe Tierra Querida + Supabase + roles"
   git push

3. Vercel detecta el nuevo push automáticamente y despliega la versión
   actualizada en unos 20-30 segundos, en el mismo link de siempre.

CREAR EMPLEADOS NUEVOS
-----------------------
1. Entra a tu proyecto en supabase.com → Authentication → Users
2. Add user → Create new user (correo + contraseña, marca "Auto Confirm
   User")
3. Esa persona ya puede iniciar sesión en la app — queda automáticamente
   como "empleado"
4. Si quieres que sea administrador, entra a la app con tu cuenta de
   administrador → ícono de engranaje (arriba a la derecha) →
   "Administración" → "Hacer admin" al lado de su nombre

QUÉ CONTIENE ESTE ZIP
-----------------------
- index.html, bundle.js, styles.css, logo.png → la app compilada y lista
  para publicar (incluye Supabase, login y roles).
- api/parse-voz.js       → función serverless que interpreta la voz con
  Gemini (sin cambios respecto a la versión anterior).
- app.source.jsx, icons.source.jsx, gemini.source.js,
  supabaseClient.source.js, styles.source.css → código fuente legible,
  por si quieres seguir editando.
- package.json           → necesario para Vercel.

NOTA SOBRE SEGURIDAD
-----------------------
La "publishable key" de Supabase que queda dentro de supabaseClient.source.js
está diseñada para ser pública (por eso Supabase la llama así) — la
protección real vive en las políticas de seguridad (Row Level Security)
que configuramos directamente en la base de datos, no en ocultar esa key.
